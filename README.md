# Empire Hub

A lightweight, dependency-free directory site that links the Portfolio Empire network of independent calculator and reference properties.

Live at: **https://theluckystrike.github.io/empire-hub/**

## Purpose

This hub serves as an editorial, dofollow index of sites we own and operate. Each entry links to a live calculator site with a short human-written description. There are no JavaScript dependencies and no tracking.
